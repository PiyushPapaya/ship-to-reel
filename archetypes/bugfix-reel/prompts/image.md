# image — bugfix-reel

If `source.capture` is true, the `problem` and `code-diff` beats should sit
over real UI screen-capture (`capture.mjs`, Phase 3), not stock imagery — a
bugfix reel's credibility comes from showing the actual broken/fixed surface.

Where no capture exists yet (Phase 2, this archetype running standalone):
scenes render as typographic cards from `brand.palette` only — no placeholder
photography. Don't fake authenticity with generic "bug/code" stock images;
an empty, well-typeset card is more honest than a wrong one.

Optional `broll` (Phase 7): abstract, dark, low-motion — a background texture
under the hook, never competing with the headline text.
